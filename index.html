Política de Privacidad de FinanzasClaras

Última actualización: Mayo 2026

Datos que recopilamos

Recopilamos correo electrónico, nombre y datos financieros que el usuario ingresa voluntariamente (ingresos, gastos, metas de ahorro).

Uso de los datos

Los datos se usan exclusivamente para proveer las funciones de la app: gestión de presupuesto, metas de ahorro y educación financiera personalizada.

Almacenamiento

Los datos se almacenan de forma segura en Supabase. No vendemos ni compartimos datos con terceros.

Inteligencia Artificial

El chat educativo usa la API de Anthropic. Los mensajes enviados al chat se procesan por Anthropic para generar respuestas. No se almacenan conversaciones del chat.
